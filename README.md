# 雪落之前 Before Snowfall

> 一款基于 **React + TypeScript** 的数据驱动叙事视觉小说游戏。  
> 项目以 1930 年代留苏青年为叙事背景，围绕“归国 / 留苏”的关键选择，构建多分支剧情、数值系统、存档回滚、音频系统与移动端适配的完整 Web 游戏原型。

[在线体验](https://snow-before-new-thuocxi6.edgeone.cool)

---

## 项目概览

《雪落之前》是一个 Web 端叙事游戏项目。玩家将扮演留苏青年沈怀远，在异国求学、家国动荡、个人前途与归国责任之间做出选择。游戏通过剧情选择、隐藏数值、行动准备、人物信任与关键节点判定，形成多路线、多结局的叙事体验。

项目采用 **数据驱动架构**：82 个剧情场景由 JSON 配置驱动，并通过 Zod 进行运行时校验；前端使用 React + TypeScript 实现场景渲染、状态管理、存档回滚、音频播放、移动端适配与线上部署，形成完整的“开始 — 游玩 — 分支 — 结局”闭环。

## 核心功能

### 1. 数据驱动剧情系统

游戏剧情不直接写死在组件中，而是统一存放在 `game-data.json` 中。每个场景包含场景类型、背景、角色、对白、选项、条件、数值变化与跳转目标。

这种结构使剧情内容可以独立于前端组件维护，便于后续扩展、调试与路线验证。

```ts
scene -> dialogue / letter / journal / ending
choice -> condition -> effects -> nextScene
state -> save -> history -> rollback
```

### 2. 多分支选择与结局判定

游戏通过显性数值、隐藏数值、行动准备和关键选择共同影响后续剧情。

| 系统 | 说明 |
|---|---|
| 显性数值 | 学识、身心状态等，玩家可以感知变化 |
| 隐藏数值 | 担当、故土牵挂、人际信任等，影响路线倾向 |
| 行动准备 | 路线、票证、经费、资料、联系人五项准备 |
| 关键选择 | 在重要节点锁定路线或影响结局 |
| 结局判定 | 根据数值、准备项、信任值与关键选择综合触发 |

### 3. 原子化选择事务

玩家点击选项后，系统会在一次状态更新中完成以下流程：

1. 创建当前节点快照  
2. 结算选项效果  
3. 写入历史记录  
4. 推进到下一个场景  
5. 自动保存游戏状态  

这种设计可以减少状态更新过程中出现的竞态问题，保证剧情推进、数值变化和存档内容保持一致。

### 4. 存档与回滚系统

项目实现了版本化存档结构 `SaveEnvelope`，用于封装游戏状态、版本信息和迁移逻辑。

支持能力包括：

- 自动存档
- 旧版本存档迁移
- 历史节点回退
- 快照恢复
- 回滚后的历史截断

该系统适合叙事游戏中常见的“回看历史 / 回到分支点 / 重新选择”需求。

### 5. 场景模板渲染

项目将不同类型的剧情内容抽象为场景模板，并通过统一渲染入口进行分发。

| 模板 | 用途 |
|---|---|
| `dialogue` | 标准剧情对白，支持打字机动画 |
| `chapter_intro` | 章节开场页 |
| `letter` | 家书阅读与翻页 |
| `historical_event` | 历史事件说明 |
| `season_journal` | 季节札记与阶段总结 |
| `free_layout` | 自由排版页面 |
| `ending` | 结局展示 |

### 6. 音频系统

音频系统支持 BGM、环境音和 SFX 三类音频资源，并针对 Web 与移动端做了兼容处理。

主要能力包括：

- BGM intro / loop 自动衔接
- 场景切换时 crossfade 淡入淡出
- 页面隐藏时自动暂停，返回后恢复
- 首次触摸 / 点击解锁移动端 AudioContext
- OGG + MP3 fallback 兼容不同浏览器

### 7. 移动端适配

项目以 1920×1080 为逻辑画布，通过等比缩放适配不同屏幕尺寸，并针对移动端横屏体验进行布局优化。

适配内容包括：

- 横屏提示
- 移动端 HUD 压缩
- 对话框与选项按钮缩放
- 特殊场景滚动阅读
- 家书页面移动端卡片化
- 设置页、历史页、结局页防溢出
- 多分辨率横屏测试

## 工程亮点

- **数据配置化**：82 个剧情场景全部由 JSON 驱动，降低内容维护与剧情扩展成本。
- **运行时校验**：使用 Zod 对剧情数据、场景模板和选项条件进行校验，提高内容稳定性。
- **状态一致性**：通过原子化选择事务，将数值结算、历史记录、剧情推进和自动存档合并处理。
- **可回滚叙事**：支持剧情历史、节点快照和回滚恢复，适合多分支叙事游戏体验。
- **多端适配**：基于固定逻辑画布和响应式 CSS，实现桌面端与移动横屏端适配。
- **音频完整闭环**：实现 BGM、环境音、音效三通道管理，并处理移动端自动播放限制。
- **AI 协同开发**：结合 CodeBuddy 和多种 AI 创作工具完成代码、美术、音频与文本素材生产，并进行人工审核和集成。
