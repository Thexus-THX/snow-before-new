# 《雪落之前》V1 开发文档包

本目录用于把《雪落之前》V1 的策划、代码、美术、音效和编辑器操作统一交给 CodeBuddy。请保持文件名不变，并按本文件规定的顺序使用。

## 一、文档清单与阅读顺序

1. `01_CODEBUDDY_MASTER_PROMPT.md`
   - 直接交给 CodeBuddy 的总开发提示词。
   - 规定技术栈、目录、实现阶段、验收条件，以及必须读取的其他文档。

2. `02_GAME_LOGIC.md`
   - 六项长期数值、角色信任、行动准备、回滚、存档、结局判定和 19 次有效选择的逻辑规则。

3. `03_STORY_BLUEPRINT.md`
   - 创作说明、时间说明、角色设定、序章、八个季节章节、家书、历史事件和两条 V1 主结局的剧情骨架。

4. `04_ART_ASSET_SPEC.md`
   - V1 统一画风、画布规格、构图规则，以及所有美术素材的精确文件名、尺寸与用途。

5. `05_AUDIO_ASSET_SPEC.md`
   - 背景音乐、环境音、UI 音效和关键句配音的精确文件名、时长与使用场景。

6. `06_EDITOR_USER_GUIDE.md`
   - 网页可视化编辑器的使用说明，包括创建场景、拖拽素材、配置文字、选项、数值、条件、预览和导入导出。

7. `07_DATA_SCHEMA.md`
   - 游戏数据 JSON 的字段规范、类型定义、示例和校验规则。

## 二、V1 的产品定位

《雪落之前》V1 是一个可部署到服务器、通过浏览器直接打开的历史叙事选择游戏，同时内置一个面向开发团队的轻量可视化编辑器。

- 玩家端：标题页、序章、八个季节章节、文字叙事、选择、数值、家书、历史事件页、两条优先主结局、自动存档和旅程回顾。
- 编辑端：上传或选择素材、拖拽布局、添加文字、配置选择、数值、隐藏标记、条件、跳转、预览、保存、导入和导出。
- V1 优先保证完整、稳定和可部署，不做实时 AI、完整背包、多人协作、复杂小游戏或移动端精细适配。

## 三、项目固定布局

- 逻辑画布：`1920 × 1080`，固定 16:9。
- 普通场景区：`1920 × 864`。
- 底部对话 UI：`1920 × 216`。
- 顶部状态栏：约 `72px`，作为场景区上的叠加层，不额外压缩场景区。
- 网页端整体等比例缩放，不拉伸，不任意裁切关键内容。

## 五、开发顺序

必须按以下顺序开发，不允许一次性生成全部功能：

1. 项目骨架与类型定义。
2. 游戏运行器和 JSON 场景读取。
3. 标准对话场景、顶部状态栏和底部对话区。
4. 选择、数值、隐藏标记和条件系统。
5. 自动存档、历史面板和回滚。
6. 家书、章节页、历史事件页、季节札记和结局页。
7. 完整打通《电波归途》和《异乡长灯》两条 V1 主线。
8. 可视化编辑器。
9. 资源替换、音频、性能优化和部署。
10. 有余力时再扩展其他结局、档案和轻量技术互动。

## 七、发布前最低验收

- 浏览器打开后可完成：创作说明 → 标题页 → 时间说明 → 序章 → 八季 → 结局 → 旅程回顾。
- 刷新或关闭浏览器后可继续最近自动存档。
- 普通选择可从历史面板回退；关键选择确认后不可撤回。
- 所有显性数值和行动准备清单逻辑正确。
- 缺失素材时显示明确的文件名占位，不产生白屏。
- 编辑器可以导出有效的 `game-data.json`，玩家端可以直接读取。
- 静态部署后不依赖本地绝对路径。
