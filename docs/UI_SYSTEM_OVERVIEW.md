# 雪落之前 - UI系统总览

## 1. 项目定位

本项目UI系统属于：

1930s 历史档案叙事像素UI系统（Narrative Archival UI System）

特点：
- 纸质档案结构
- 苏联工业风 + 中国近代历史融合
- 非现代UI系统
- UI即“档案物件”

---

## 2. UI设计原则

### ❌ 禁止
- 现代UI（Material / iOS / Web UI）
- 科技感HUD
- 渐变/霓虹/发光效果
- 扁平化图标系统

### ✅ 必须遵守
- 纸张 / 文件 / 信件 / 票据结构
- 像素叙事插画风
- 低饱和（旧纸 + 铁锈红 + 冷蓝）
- UI必须“像真实档案”

---

## 3. UI资产来源

所有UI来自：

/assets/ui/

分类如下：
- buttons/
- panels/
- icons/
- frames/
- letters/

---

## 4. UI系统结构

UI分三层：

### Asset Layer（图片）
PNG资源

### Component Layer（组件）
Button / Panel / Icon

### Layout Layer（页面）
Dialogue / Archive / Journal / HUD
