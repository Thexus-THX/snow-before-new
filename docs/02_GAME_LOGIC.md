# 《雪落之前》V1 游戏逻辑

## 一、核心原则

1. 方向由玩家决定，方式与结果由前七日积累决定。
2. 所有长期数值都综合影响结局，不存在“一项数值对应一个结局”。
3. 关键标记必须来自具体事件，不能凭空生成。
4. 分歧不等于失信；只有欺骗、失约、利用或明显伤害关系才降低角色信任。
5. V1 无中途失败。数值低会减少后续道路，而不是突然结束游戏。
6. 玩家看得到显性数值变化，看不到隐藏数值、角色信任数字和路线倾向。

---

## 二、长期数值

所有长期数值均为 0—10 整数，使用 `clamp(0, 10)`。

### 显性数值

| 字段 | 中文名 | 初始值 | 前台表现 | 主要作用 |
|---|---|---:|---|---|
| `knowledge` | 学识 | 4 | 数字与等级 | 技术选项、研究成果、资料完整度 |
| `wellbeing` | 身心状态 | 7 | 数字与状态词 | 高强度行动、接受帮助、结局代价 |
| `preparation` | 行动准备 | 1 | 数字与清单 | 归国方式、路线可行性、执行质量 |

### 隐藏数值

| 字段 | 中文名 | 初始值 | 主要作用 |
|---|---|---:|---|
| `responsibility` | 担当 | 4 | 技术责任、时代责任、结局动机与完成度 |
| `homesickness` | 故土牵挂 | 5 | 家书、家庭线、归国动机、尾声情感 |
| `socialTrust` | 总体人际信任 | 4 | 多方支持能力与综合结局评分 |

### 数值变化幅度

- 普通选择：通常 `±1`。
- 关键选择：通常 `±2`。
- 极端且有明确代价的关键选择：最多 `±3`。
- 没有合理因果：不改变数值。

## 三、行动准备五项清单

行动准备不是独立随意加减，而是五项准备状态之和。

每项取值：

- `0`：未开始。
- `1`：部分完成。
- `2`：准备完成。

```text
preparation = route + documents + funds + technicalMaterials + contact
```

| 字段 | 中文名 | 初始值 | 说明 |
|---|---|---:|---|
| `route` | 归国路线 | 0 | 是否掌握可行路线及其可靠程度 |
| `documents` | 身份与票证 | 0 | 身份文件、通行材料与票证 |
| `funds` | 经费 | 1 | 旅费与基本行动资金 |
| `technicalMaterials` | 技术资料 | 0 | 研究笔记、公开资料与整理完成度 |
| `contact` | 可靠联系人 | 0 | 可提供路线、证明或协助的人 |

任何代码修改五项准备后，都必须重新计算 `preparation`。

高总分不能掩盖关键缺口。例如没有路线时，不得开放“按确认路线启程”。

## 四、角色独立信任

初始值：

| 字段 | 角色 | 初始值 |
|---|---|---:|
| `trustChen` | 陈绍衡 | 6 |
| `trustNadya` | 娜佳 | 4 |
| `trustBelov` | 别洛夫导师 | 4 |
| `trustIvan` | 伊万师傅 | 3 |

统一阶段：

| 数值 | 后台阶段 |
|---:|---|
| 0—2 | 疏离 |
| 3—4 | 熟识 |
| 5—6 | 信任 |
| 7—8 | 可靠 |
| 9—10 | 深厚 |

角色专属含义：

- 陈绍衡可靠：即使存在分歧，仍可能分享路线、同行或在关键时刻合作。
- 娜佳可靠：协助整理资料，触发完整告别与重要情感回收。
- 别洛夫可靠：相信主角的决定经过准备，可提供推荐、公开资料或制度内帮助。
- 伊万可靠：提供现场经验、设备检查和工厂协助。

信任变化建议：

- 普通合作或坦诚：`+1`。
- 重要支持或承担责任：`+2`。
- 一般分歧：`0`。
- 轻微失信：`-1`。
- 关键欺骗或伤害：`-2`。
- 极端背叛：最多 `-3`。

### 总体人际信任

```text
base = round((trustChen + trustNadya + trustBelov + trustIvan) / 4)
socialTrust = clamp(base + cooperationModifier, 0, 10)
```

- `cooperationModifier` 初始为 0。
- 只允许少量关键合作或严重失信行为改变，范围建议 `-2` 到 `+2`。
- 至少三位角色达到“可靠”，才视为形成稳定支持网络。
- 角色专属帮助永远只检查对应角色信任，不得用总体信任替代。

## 七、关键标记反馈

关键标记不显示内部变量名。玩家点击关键选项前，只看到 `【关键选择】`。

选择完成后可出现一句叙事化反馈，例如：

- “陈绍衡把路线写在了纸背面。”
- “别洛夫没有继续追问，只把文件往前推了一寸。”
- “你把母亲的来信重新放回贴身口袋。”

普通选择不需要特殊标记提示。

## 八、路线倾向

字段：

- `returnTendency`，初始 0。
- `stayTendency`，初始 0。

只在第六日以后，明确推进某方向时 `+1`。

用途：

- 第七日优先展示的场景顺序。
- 季节札记语气。
- 配角对白。
- 界面细节。

禁止：

## 十一、V1 两条主结局与未来五结局

### V1 优先实现

1. `ending_electric_wave_return`：《电波归途》
   - 所有归国具体方式都进入该主结局。
   - 根据最终方式、准备、资料、关系和状态生成不同尾声段落。

2. `ending_foreign_lamp`：《异乡长灯》
   - 所有暂留具体方式都进入该主结局。
   - 重点表现成就、稳定与未完成归期之间的遗憾，而不是道德惩罚。

### 未来拆分

- 《孤身踏雪》：准备不足但坚持归国。
- 《遥寄星火》：留苏完成研究并支援国内。
- 《迟来的归期》：延后后再踏上归途。

### 结局判定结构

```text
玩家最终具体行动
+ 必要条件
+ 六项长期数值综合评分
+ 角色信任
+ 准备清单
+ 关键物品与标记
= 主结局与尾声变体
```

结局页只显示结局名称，不显示 GOOD / BAD 或等级。
