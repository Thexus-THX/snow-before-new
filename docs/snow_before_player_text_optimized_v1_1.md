## 十八、整体文字优化说明

### 本版主要改动

1. **叙事口吻统一**  
   普通旁白尽量改为第三人称限知视角：沈怀远 / 他。选择项仍保留动作式表达，方便玩家操作。

2. **时代感增强**  
   家书部分减少现代心理表达，改为更克制的家庭书信语气。

3. **情绪更克制**  
   减少“命运”“永别”“传奇”等过度直白词汇的密度，让情绪通过物件、动作、停顿表达。

4. **主题更清晰**  
   保留“技术为谁所用”“归国与留下不是善恶二分”“责任不是口号而是取舍”的核心表达。

5. **UI文本去开发痕迹**  
   将“阶段 1 · 项目骨架”等开发阶段文字改为玩家可见的正式表达。

6. **个别笔误与不自然表达修正**  
   例如“分险检查后”建议玩家侧显示为“分批检查后”或“高风险批次检查后”。

- `src/pages/SettingsPage.tsx`：设置页底部文字。

- `src/components/scenes/SceneFallback.tsx`：降级提示。
